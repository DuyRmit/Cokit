How to use IfraGen

Turn an HTML activity into a live embed on your Canvas page

Before you upload
  • One file only. Compress everything into a single .html file, with CSS and JavaScript written inside it. Activities that link to separate files won't run on Canvas.
  • Name it clearly. Use COURSE-CODE_MODULE-NUMBER_FILE-NAME, for example ABCD1234_03_reflection-tracker.html.
  • Keep HTML files together. Create a dedicated folder for them in Files so they are easy to find and manage.
  1. 1

    Upload your file to Canvas Files

    In your course, open Files and go to your HTML folder (use + Folder to create one). Click Upload and choose your HTML file.

  2. 2

    Copy the file link

    Click the file name to open its preview, then copy the full link from your browser's address bar. It must contain ?preview= followed by a number.

  3. 3

    Generate the code in IfraGen

    Paste the link into Paste the File Link and set the height so your whole activity is visible. Click Generate Iframe Code, then Copy.

    Tick aria-hidden only if the activity is not accessible. It hides the embed from screen readers, so give those users another way to complete the task. If the activity is accessible, leave it unticked.
  4. 4

    Open your Canvas page in edit mode

    Go to the page where the activity should appear and click Edit.

  5. 5

    Click Embed in the editor toolbar

    Place your cursor exactly where you want the activity, then click the Embed icon in the toolbar.

  6. 6

    Paste the code and submit

    Paste the code into Embed Code and click Submit. Save the page and your activity will appear on Canvas.
